## Featured Project

### [TicTacToe — Application Delivery & Kubernetes Operations](https://github.com/vtarykin/tictactoe)

A Java/Spring Boot application used to build a practical DevOps environment focused on automated delivery and Kubernetes operations.

- **CI/CD:** Automated application builds, Docker image publishing to GHCR, and Kubernetes deployment with GitHub Actions and a self-hosted runner.
- **Infrastructure as Code:** Kubernetes resource definitions using Terraform and Helm.
- **Autoscaling:** Configured Kubernetes HPA and verified scaling from 1 to 3 replicas under synthetic CPU load.
- **Observability:** Deployed Prometheus and Grafana to monitor workload and resource metrics.
- **Alerting:** Configured Alertmanager notifications to Telegram and tested alert delivery.

The project runs on a local Kubernetes cluster created with `kind` and demonstrates the integration of delivery automation, orchestration, monitoring, and alerting.

Simplified implementations of the basic Unix command-line utilities `cat` and `grep`, written in C.
